# 📊 Log Analyzer Project

This project is designed to analyze HTTP logs and present meaningful insights from them. It consists of a modular structure where logs are parsed, processed, and visualized using different components.

# 🛠️ Set up

```
# Create virtual environment
python -m venv myenv

# Activate it
source myenv/bin/activate       # On Linux/macOS
myenv\Scripts\activate          # On Windows

# Install libraries
pip install -r requirements.txt

# Run the app
python -m app.main
```
